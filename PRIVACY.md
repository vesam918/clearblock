# Privacy Policy

ClearBlock is designed to work locally.

- It does **not** collect, transmit, sell, or share browsing history or personal data.
- It does **not** include analytics, telemetry, advertising, affiliate links, or accounts.
- Settings, allowlisted domains, custom blocked domains, and the aggregate blocked-request counter remain in Chrome's local extension storage.
- Filtering is performed by Chrome's Manifest V3 Declarative Net Request API using rules packaged with the extension.
- The extension requests access to websites solely to apply user-selected blocking and allowlisting rules.

ClearBlock does not operate a backend service. Questions may be submitted through the project's GitHub issue tracker.
